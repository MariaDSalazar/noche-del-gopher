# La Noche del Gopher

Repaso de Halloween sobre Go: slices y maps, objetos en Go y diagrama de clases UML, y structs.

## Cómo se usa

- Escriba sus nombres y sus apellidos y empiece el juego.
- Hay tres salas, una por temática, con 25 preguntas de teoría en total: opción múltiple, verdadero o falso y selección múltiple. Puede hacerlas en el orden que quiera.
- Si falla, vuelve a intentarlo; solo cuenta como acierto lo que resuelve al primer intento. Al acertar, ve por qué esa es la respuesta.
- Al superar las tres salas obtiene un certificado de culminación que se puede imprimir o descargar en PDF, desde el computador o el celular.
- No puede salir de la página mientras juega: si abre otra pestaña, cambia de aplicación, abre otra ventana o recarga, el juego se bloquea y se reinicia desde el principio. Al intentar cerrar o recargar, el navegador pide confirmar.

Las preguntas, las opciones y las explicaciones viajan cifradas: cada pregunta se abre al resolver la anterior. El juego no envía datos a ningún servidor.

## Cómo se corre

Es una página estática: abra `index.html` desde cualquier servidor de archivos (por ejemplo, GitHub Pages) en un navegador actualizado.
